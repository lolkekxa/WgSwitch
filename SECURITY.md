# Безопасность

WgSwitch держит ключи от ваших серверов, поэтому здесь — что именно программа хранит, куда ходит в сеть
и как сообщить об уязвимости.

## Сообщить об уязвимости

**Не открывайте публичный issue.** Напишите приватно:

- [Report a vulnerability](https://github.com/lolkekxa/WgSwitch/security/advisories/new) — приватный отчёт на GitHub;
- или почта **[lkxa.dev@gmail.com](mailto:lkxa.dev@gmail.com)**, тема «WgSwitch security».

Что приложить: версию (Настройки → внизу), Windows или Android, шаги, чтобы повторить, и чем это грозит.
Ответ — в течение 3 дней; исправление выходит отдельным релизом, в его описании будет ссылка на отчёт
(с вашего согласия — и ваше имя).

## Поддерживаемые версии

Исправления выходят для последнего релиза. Установленная копия на Windows сама предлагает обновиться;
на Android — скачайте новый APK из [релизов](https://github.com/lolkekxa/WgSwitch/releases/latest),
он ставится поверх.

## Что программа хранит

| Где | Что | Защита |
|---|---|---|
| Windows: `C:\ProgramData\WgSwitch\*.conf` | конфиги с **приватными ключами** | папка доступна только Администраторам и SYSTEM |
| Windows: `%APPDATA%\WgSwitch\settings.json` | имена серверов, пути, IP для проверки, флаги | ключей нет |
| Android: приватная папка приложения | конфиги и настройки | другим приложениям недоступна; исключена из облачной копии Google и переноса на новый телефон |
| Файл `.wgsb` (резервная копия) | все серверы и ключи | AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 600 000 итераций |
| Сервер: `/etc/wgswitch/clients/` | конфиги устройств, созданных `wgswitch-server` | права `600`, папка `700`, только root |

Приватный ключ читается только там, где без него нельзя: создание ключей, резервная копия, переключение
«весь интернет через VPN» (переписывается `AllowedIPs` в том же файле), публичный ключ телефона
(вычисляется внутри движка). В логи, настройки и на экран он не попадает. Handshake и трафик на ПК читаются
через `wg show … latest-handshakes` / `transfer`, а не `dump`, который выводит ключ.

Конфиг для телефона, созданный на ПК («Телефон → QR-код»), нигде не сохраняется: живёт, пока открыт экран,
а QR и блок для сервера размыты, пока не нажать «Показать».

## Куда программа ходит в сеть

| Кто | Куда | Зачем |
|---|---|---|
| WgSwitch на Windows | `api.github.com`, `github.com` | проверка обновлений (выключается в настройках) и скачивание установщика; SHA-256 сверяется с `SHA256SUMS.txt` релиза |
| Установщик | `download.wireguard.com` | только по галочке «Установить WireGuard для Windows» |
| WgSwitch на Android | никуда, кроме ваших серверов | сканер QR — сервисы Google на телефоне, по кнопке |
| Оба | ваши серверы внутри туннеля | пинг для статуса, проверка портов в панели сервера |

Телеметрии, аналитики и сбора ошибок нет.

## Как проверить, что файл не подменён

Каждый файл релиза собран GitHub Actions из этого репозитория. Проверить можно двумя способами:

```powershell
# контрольная сумма — сравнить с SHA256SUMS.txt в релизе
Get-FileHash .\WgSwitch-Setup-1.2.0.exe -Algorithm SHA256

# подтверждение сборки от GitHub (нужен GitHub CLI): какой workflow, из какого коммита
gh attestation verify .\WgSwitch-Setup-1.2.0.exe --repo lolkekxa/WgSwitch
```

APK подписан постоянным ключом проекта: Android не поставит поверх него APK, подписанный другим ключом.
Отпечаток сертификата (SHA-256):

```
32:DB:03:20:73:F4:4A:B0:5D:F3:1C:AC:37:4A:8E:FE:69:1D:D4:63:2A:D5:22:5D:13:F1:02:8F:45:A0:2D:CC
```

Проверить: `apksigner verify --print-certs WgSwitch-1.2.0.apk`.
