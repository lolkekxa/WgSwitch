## ✦ 0. Что понадобится

| Где | Что | Зачем |
|---|---|---|
| Сервер | VPS на **Ubuntu 22.04 / 24.04**, доступ под `root` | туннель; для AmneziaWG нужен именно Ubuntu |
| Сервер | **веб-консоль хостера** (VNC) — найдите её в панели заранее | запасной вход, если SSH открыт только через VPN |
| ПК | Windows 10/11, **WireGuard для Windows** | WgSwitch управляет туннелем через официальный клиент |
| ПК | WgSwitch — установщик из [релизов](https://github.com/lolkekxa/WgSwitch/releases) | |
| Телефон | Android 8+, WgSwitch (APK) | на телефоне движок встроен, ничего ставить не нужно |

**Два движка — коротко.** Обычный **WireGuard** работает везде, где его не режут. **AmneziaWG** — тот же WireGuard
с маскировкой пакетов: нужен, если провайдер блокирует WireGuard. Признак блокировки: подключение на пару секунд,
потом «Нет ответа от сервера», и так по кругу. Телефон понимает оба движка; WgSwitch на ПК пока — только обычный
WireGuard. Поэтому дальше на сервере поднимаются **оба туннеля**: WireGuard для ПК и AmneziaWG для телефона.

**Правило одного ключа.** У каждого устройства — свой ключ и свой адрес. Один и тот же конфиг на ПК и телефоне
одновременно не работает: сервер перекидывает связь между ними.

## ✦ 1. Сервер

### 1.1. Зайти на сервер

```bash
ssh root@<внешний IP сервера>
```

Если SSH открыт только через VPN, а VPN ещё нет (или вы как раз всё переустанавливаете) — откройте веб-консоль
в панели хостера. В консоли символы вводятся в **раскладке компьютера**: переключитесь на английскую,
иначе пароль «не подойдёт».

### 1.2. Если на сервере уже был WireGuard и вы ставите с нуля

Сначала копия, потом снос:

```bash
tar czf /root/wireguard-backup-$(date +%F).tgz /etc/wireguard /etc/amnezia 2>/dev/null
systemctl disable --now wg-quick@wg0
rm -f /etc/wireguard/*
```

Если SSH ходит через этот туннель, связь оборвётся — дальше в веб-консоли или по внешнему IP.
Пакеты (`wireguard-tools`) удалять не нужно.

### 1.3. Поставить скрипт `wgswitch-server`

```bash
curl -fsSL https://raw.githubusercontent.com/lolkekxa/WgSwitch/main/server/wgswitch-server.sh \
  -o /usr/local/bin/wgswitch-server && chmod +x /usr/local/bin/wgswitch-server
```

<details>
<summary>Скопировать с ПК вместо скачивания</summary>

Из **PowerShell на ПК** (не в SSH-сессии сервера!), пока доступ к серверу есть:

```powershell
scp Z:\apps\vpn-client\server\wgswitch-server.sh root@<IP сервера>:/usr/local/bin/wgswitch-server
```

затем на сервере: `chmod +x /usr/local/bin/wgswitch-server`.
</details>

Дальше всё делается одной командой: `wgswitch-server`. В квадратных скобках — ответ по умолчанию:
нажмите Enter, чтобы его принять.

### 1.4. Туннель для ПК — WireGuard

```bash
wgswitch-server
```

На пустом сервере скрипт сразу предлагает создать туннель:

| Вопрос | Что ответить | Пояснение |
|---|---|---|
| Движок | `2` — WireGuard | для WgSwitch на ПК |
| Порт UDP `[51820]` | Enter | стандартный порт WireGuard |
| Подсеть туннеля `[10.8.0.0/24]` | Enter | сервер получит `10.8.0.1`, устройства — `10.8.0.2`, `.3`… |
| Весь интернет устройств через сервер (NAT)? `[n]` | `n` или `y` | `y` — если хотите в WgSwitch тумблер «Весь интернет через VPN». Для доступа к SSH и панелям сервера не нужно |
| Адрес сервера для устройств `[x.x.x.x]` | Enter | внешний IP, найден сам. Можно вписать домен |
| Добавить первое устройство? `[y]` | Enter | сразу добавим ПК |
| Имя устройства `[phone]` | `pc` | для себя, видно в списке устройств |
| IP устройства в туннеле `[10.8.0.2]` | Enter | первый свободный |
| Как сервер будет называться в WgSwitch `[имя-сервера]` | Enter или своё имя | под этим именем сервер появится в программе |
| Весь интернет устройства через этот сервер? `[n]` | Enter | `y` — весь трафик ПК пойдёт через сервер (нужен NAT из шага выше) |

В конце — QR-код (для ПК он не нужен) и строка вида:

```
Для ПК файл: /etc/wgswitch/clients/wg0-pc.conf
  забрать на ПК: scp root@x.x.x.x:/etc/wgswitch/clients/wg0-pc.conf .
```

Запомните её — это конфиг ПК, он понадобится в [разделе 2](#-2-пк-windows).

> Если у хостера есть свой файрвол в панели (облачный, security group) — откройте там `51820/udp`.
> `ufw` на самом сервере скрипт настроит сам.

### 1.5. Туннель для телефона — AmneziaWG

Скрипт после первого туннеля показывает меню. Выберите `6 — Новый туннель`:

| Вопрос | Что ответить | Пояснение |
|---|---|---|
| Движок `[1]` | Enter — AmneziaWG | ставится из PPA amnezia за 6 шагов, на экране — номер шага и секунды. Самый долгий — сборка модуля под ядро, 1–5 минут: это не зависание |
| Порт UDP `[51821]` | Enter | второй туннель — на соседнем порту |
| Подсеть туннеля `[10.9.0.0/24]` | Enter | своя подсеть, не пересекается с WireGuard |
| NAT, адрес сервера | как в 1.4 | |
| Добавить первое устройство? `[y]` | Enter | |
| Имя устройства `[phone]` | Enter | |
| Остальное | Enter | имя сервера будет `<имя>-awg` |

На экране появится **QR-код** — его отсканирует телефон в [разделе 3](#-3-телефон-android).
Можно не спешить: позже его покажет `wgswitch-server` → `4 — Показать QR устройства снова`.

> Не влезает QR — уменьшите шрифт терминала (Ctrl + колёсико мыши) или разверните окно.
> Откройте в панели хостера ещё и `51821/udp`, если там есть свой файрвол.

Если на этом шаге ошибка «Модуль AmneziaWG не загрузился» — обновите ядро и перезагрузите сервер
(`apt full-upgrade -y && reboot`), потом повторите пункт `6`.

### 1.6. Проверить

```bash
wgswitch-server list
```

Покажет оба туннеля и устройства. Пока устройства не подключались — «не подключалось»; после подключения —
«N с назад». Выйти из меню — `0`.

## ✦ 2. ПК (Windows)

### 2.1. Установить

1. Скачайте `WgSwitch-Setup-X.Y.Z.exe` из [релизов](https://github.com/lolkekxa/WgSwitch/releases) и запустите.
   Если WireGuard для Windows ещё не стоит — оставьте галочку «Установить WireGuard для Windows», установщик скачает его сам.
2. WgSwitch просит права администратора при запуске — так устроено управление службами WireGuard.

### 2.2. Забрать конфиг с сервера

В **PowerShell на ПК** — команда из конца шага 1.4, но с понятным именем файла. **Имя файла станет именем сервера
в программе**, поэтому сразу назовите его как хотите видеть, например `digimart.conf`:

```powershell
mkdir $env:USERPROFILE\WgSwitch -Force
scp root@<IP сервера>:/etc/wgswitch/clients/wg0-pc.conf $env:USERPROFILE\WgSwitch\digimart.conf
```

> WgSwitch использует файл **там, где он лежит**, и не копирует его. Не кладите его во «Временные» и не удаляйте
> после добавления. В файле приватный ключ ПК — не отправляйте его в мессенджеры.

### 2.3. Добавить сервер

**Если серверов в программе ещё нет** — откроется мастер «Настроим туннель»:

1. «С чего начнём» → **«У меня есть .conf»** → выберите `digimart.conf`.
2. Готово: сервер появится на главной.

**Если серверы уже есть:**

- новый сервер — шестерёнка → в карточке «Сервер» **«+ Добавить»** → «У меня есть .conf»;
- **заменить конфиг старого** (например, после переустановки сервера) — выберите сервер капсулой на главной →
  шестерёнка → строка **«Конфиг»** → выберите новый файл → **«Сохранить»**. Старый ключ сервера после
  переустановки больше не подходит, поэтому замена обязательна.

### 2.4. Проверить «IP для проверки»

Шестерёнка → **«IP для проверки»** должен быть адресом сервера в туннеле: `10.8.0.1` для подсети из шага 1.4.
По нему WgSwitch понимает, что сервер жив. Неверный адрес — вечное «Нет ответа», хотя туннель работает.

### 2.5. Подключиться

Нажмите круглую кнопку на главной:

| Что видно | Что значит |
|---|---|
| Жёлтая дуга, «Подключение» | служба WireGuard запускается, ждём первый ответ сервера. Повторное нажатие отменяет подключение |
| Зелёное кольцо, «Подключено», пинг в мс | всё работает |
| Красное, «Нет ответа от сервера» | туннель поднят, но сервер молчит — см. [раздел 5](#-5-если-не-работает) |

Проверьте на сервере `wgswitch-server list` — у `pc` появится «N с назад».

### 2.6. Полезное на ПК

- **Кнопка сервера** рядом с шестерёнкой: SSH, SFTP (FileZilla), веб-панель сервера; точка — открыт ли порт.
- **Телефон → QR-код** там же — QR для телефона *обычного WireGuard* (со своим ключом). Для AmneziaWG пока
  используйте QR из скрипта на сервере (шаг 1.5).
- **Резервная копия** (Настройки → «Экспорт»): все серверы и конфиги в один зашифрованный `.wgsb`. Его же
  открывает WgSwitch на телефоне.
- **Переподключать сам** — после сна и смены сети туннель перезапускается за секунды.

## ✦ 3. Телефон (Android)

### 3.1. Установить

1. Скачайте `WgSwitch-X.Y.Z.apk` из [релизов](https://github.com/lolkekxa/WgSwitch/releases) прямо на телефон (или перенесите с ПК) и откройте его.
2. Android спросит про установку из неизвестных источников — разрешите для приложения, через которое открыли
   файл (Файлы, Telegram…).
3. При первом запуске WgSwitch попросит разрешение на **уведомления** — разрешите, если нужна плашка в шторке.

### 3.2. Добавить сервер по QR

1. WgSwitch → **«Сканировать QR-код»** (при первом запуске это на главном экране; потом — шестерёнка →
   **«+ Добавить»**).
2. Наведите камеру на QR из шага 1.5 на экране ПК.
3. Откроется «Новый сервер»: **имя и IP для проверки уже заполнены** — их подставил скрипт. Endpoint — адрес
   сервера, для сверки.
4. Ниже — блок **«(02) На сервере»**. Для QR из скрипта ничего делать не нужно: скрипт уже добавил телефон на
   сервер. Этот блок нужен, если конфиг пришёл откуда-то ещё.
5. **«Добавить»**.

Другие способы: **«Файл .conf»** — выбрать конфиг из памяти телефона; **«Резервная копия .wgsb»** — файл
экспорта с ПК и пароль от него.

### 3.3. Подключиться

1. Первое нажатие на кнопку — Android спросит **«Запрос на подключение»** → **OK**. Один раз.
2. Дальше как на ПК: жёлтая дуга → зелёное «Подключено». В строке состояния появится значок ключа.
3. Телефон вибрирует: щелчок при нажатии, тики пока идёт подключение, двойной толчок — подключилось,
   глухой удар — сервер не отвечает. Выключается в настройках.

> На Android одновременно работает **только один VPN**. Переключение на другой сервер (капсулы сверху)
> выключает предыдущий; другой VPN-приложение тоже отключит WgSwitch.

### 3.4. Удобства

| Что | Где | Как пользоваться |
|---|---|---|
| Уведомление | шторка | состояние и пинг; кнопки «Включить/Выключить» и «→ следующий сервер». Закрывается свайпом, вернётся при следующем включении. Отключается в настройках |
| Плитка | шторка → карандаш «Изменить» → перетащить **WgSwitch** наверх | включить/выключить одним касанием |
| Виджет | долгое нажатие на пустом месте рабочего стола → «Виджеты» → WgSwitch | кнопка с цветным кольцом, имя сервера, состояние |
| Постоянный VPN | Настройки WgSwitch → «Постоянный VPN» → в настройках Android включить для WgSwitch | VPN поднимается сам после перезагрузки |
| Ключ телефона | Настройки → «(02) На сервере» | публичный ключ и готовый блок `[Peer]` — касание копирует |

## ✦ 4. Управление устройствами

Всё — `wgswitch-server` на сервере:

| Пункт меню | Когда |
|---|---|
| `1` Добавить устройство | новый телефон, ноутбук: имя → QR и файл. Ключ создаётся на сервере |
| `2` Добавить по ключу | ключ создан на самом устройстве: мастер WgSwitch на ПК («Создать новый конфиг») или «Телефон → QR» в WgSwitch. Вставьте строку `PublicKey = …` из их блока `[Peer]` |
| `3` Список | кто есть и когда подключался |
| `4` Показать QR снова | потеряли QR, переустановили телефон |
| `5` Удалить | потерянное или чужое устройство — доступ пропадает сразу |
| `6` Новый туннель | ещё один движок или порт |

То же без меню: `wgswitch-server add`, `add-key`, `list`, `qr`, `remove`, `new`.

**Почему это безопасно для работающих подключений.** Скрипт добавляет и удаляет устройства точечно (`wg set` +
правка файла) и не трогает остальных — SSH через VPN не оборвётся. Ключ сервера хранится строкой `PrivateKey`
в конфиге: старую схему с `PostUp = wg set %i private-key …` скрипт переносит сам при первом добавлении
и оставляет рядом копию `.bak`.

Если правите `/etc/wireguard/wg0.conf` вручную и применяете `wg syncconf`, помните: команда оставляет **только**
пиров из файла. Кого там нет — отключится.

## ✦ 5. Если не работает

| Что видно | Причина | Что сделать |
|---|---|---|
| «Нет ответа», в `wgswitch-server list` устройство «не подключалось» | сервер не знает ключ устройства | добавить устройство скриптом (`1` или `2`); для конфига с ПК — проверить, что взят файл именно этого сервера |
| То же, но порт закрыт | файрвол хостера | открыть `51820/udp` / `51821/udp` в панели хостера |
| Подключается на 5–20 секунд, потом «Нет ответа», снова и снова | провайдер режет WireGuard | AmneziaWG: шаг 1.5 и QR на телефоне. На ПК — пока только через другой VPN или сеть |
| «Подключено» не загорается, хотя handshake есть (в «Подробно на главной») | неверный «IP для проверки» | `10.8.0.1` для WireGuard из шага 1.4, `10.9.0.1` для AmneziaWG |
| Всё отвалилось после `wg syncconf` | ключ сервера был в `PostUp` или устройства нет в файле | [TROUBLESHOOTING.md](../TROUBLESHOOTING.md#после-wg-syncconf-отключились-все-устройства) |
| Пароль в веб-консоли «неверный» | русская раскладка | переключиться на английскую перед вводом |
| ПК и телефон мешают друг другу | один конфиг на двух устройствах | у каждого своё устройство в `wgswitch-server` |

Если ничего не подошло — на сервере `wgswitch-server list` и `wg show` (`awg show` для AmneziaWG),
на ПК — скриншот WgSwitch с включённым «Подробно на главной». В выводе только публичные ключи.
